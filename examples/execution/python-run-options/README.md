# Python Run Options

This example uses the v4 public Python API to construct runtime options,
validate exact stage runtime settings, merge a runtime profile, and inspect
executor capability diagnostics.

## Public Python Surface

This example teaches `RunOptions`, `merge_run_options`,
`validate_stage_runtime_options`, and `validate_executor_capabilities`.

Run from the repository root:

```sh
uv run python examples/execution/python-run-options/run_options_api.py
```
