# Implementation Plans Moved

Roadmap implementation artifacts now live under `docs/roadmap/`.

- Canonical roadmap: `docs/roadmap.md`
- Stage planning: `docs/roadmap/stage-<id>/planning.md`
- Stage implementation plan: `docs/roadmap/stage-<id>/implementation-plan.md`
- Stage phase artifacts: `docs/roadmap/stage-<id>/phases/`

Post-roadmap units preserve their roadmap IDs as suffixes, for example
`docs/roadmap/stage-9-post/implementation-plan.md`.
