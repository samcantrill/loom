# Repository Improvement Log

This is Loom's current queue for reusable workflow, design, contract, interface,
skill, and tooling improvements. Immediate defects, diagnostics, and phase
acceptance remain in source/tests, roadmap artifacts, PRs, or validation evidence.
Use `$loom-process-improvement` for admission, consolidation, and promotion.

Admit recurrence, a problem crossing supported consumers/boundaries, or a
demonstrated missing shared rule. Severity and a long diagnosis alone do not
qualify. Keep concise evidence, a reusable lesson, one canonical promotion owner,
the smallest action, verification trigger/evidence, and residual uncertainty.
Search by lesson and owner before allocating the next RI-### ID. Logging never
widens the active task or adds a product acceptance gate.

## States

| State | Meaning |
| --- | --- |
| observed | A reusable pattern may exist; cause or owner is unsettled |
| triaged | Evidence supports the pattern, owner, and proposed action |
| actioned | The shared improvement landed but has not been exercised |
| monitoring | Immediate checks passed; realistic later use remains |
| closed | Later use or a deterministic contract verified the improvement |
| declined | Evidence did not justify a reusable improvement |
