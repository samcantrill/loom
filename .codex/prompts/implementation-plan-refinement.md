# Implementation Plan Correction

Optional bounded correction after one plan review.

Edit only the named manifest or phase plans. Resolve concrete blockers and
required simplifications. Prefer removal or deferral over more explanation.
Preserve approved behavior and design. Keep phases vertical, ownership clear,
tests proportional, and private implementation discretionary.

If a finding requires new behavior or a reopened design decision, mark the plan
blocked and stop. Do not implement code, add optional hardening, create a
sidecar, or request another loop.
