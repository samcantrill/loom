# Roadmap Stage Functionality Agreement

Manager-local pass for the active planning.md.

1. Ensure each included capability maps to a current user outcome, consumer,
   supported path, or demonstrated failure.
2. Keep requirements concrete, dependency-aware, and non-duplicative.
3. Resolve repository-backed defaults locally.
4. Ask one unresolved material question at a time with recommendation, tradeoff,
   residual risk, and exact feedback needed.
5. After each answer, update the requirement, queue state, and concise decision
   log.
6. Lock behavior only when defaults, failures, unsupported behavior, and
   deferrals are explicit.

Do not begin design while a material functionality item is unresolved or merely
pending approval.
